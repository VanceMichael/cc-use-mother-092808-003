# 人工智能设计方案权属与工程取舍

追踪人工智能辅助设计的素材、模型、候选、仿真、人工修改和权属。

## 参与方与事实

主要参与方包括制造企业设计中心、工程仿真团队、设计师、模型与素材供应方、量产评审人员。领域资料记录以下已经确认的事实：

- 大会强调人工智能与设计深度耦合
- 汽车研发用人工智能气动智能体缩短优化时间
- 本土设计进入全球产品网络

## 业务约束

- 设计谱系
- 模型与素材许可
- 多目标评审
- 仿真回执
- 量产冻结

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_003.py` 负责读取和校验这些资料。

## 方案治理服务

`src/governance/` 在领域约束之上实现了一套方案治理服务（设计见
`docs/governance-service.md`）：

- 素材权利来源、供应商模型版本与许可、提示、生成候选、仿真参数与回执、
  人工评审、派生/合并关系、量产决定共享一条哈希链事件日志；
- 合并按权重分摊贡献、继承最严许可（权限交集、义务并集），同一来源经
  多次派生或菱形谱系不重复计算；
- 机密项目对无密级团队统一返回“不存在或无权访问”；提交人不得批准自己
  的许可例外；
- 许可收窄立即限制新派生，旧评审凭当时许可版本快照仍可验证；
- 仿真设备重传同一会话只记录一次；摘要变化时候选及全部后代停在待查；
- 评审期间重启后待办与到期许可由事件重放延续；量产冻结输出可沿谱系
  回溯机器建议、人工选择、工程/审美取舍与权属确认的谱系包。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
