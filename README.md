# 人工智能设计方案权属与工程取舍

追踪人工智能辅助设计的素材、模型、候选、仿真、人工修改和权属。

## 参与方与事实

主要参与方包括制造企业设计中心、工程仿真团队、设计师、模型与素材供应方、量产评审人员。领域资料记录以下已经确认的事实：

- 大会强调人工智能与设计深度耦合
- 汽车研发用人工智能气动智能体缩短优化时间
- 本土设计进入全球产品网络

## 业务约束

- 设计谱系
- 模型与素材许可
- 多目标评审
- 仿真回执
- 量产冻结

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_003.py` 负责读取和校验这些资料。

## 方案治理服务

`src/governance/` 是研发中心的方案治理服务，覆盖从任务到量产的完整链条：

- **任务与约束**：`create_brief` 记录任务目标与约束；机密任务对无关团队连存在性都不暴露。
- **权利与许可**：素材权利来源、供应商模型版本与许可统一登记；许可只追加版本、只能收窄，旧版本永久保留。
- **候选与派生**：候选记录模型版本、提示内容、素材与父候选；合并时继承全部来源限制的并集，贡献按唯一来源平分，同一来源不因多次派生重复计算；许可到期即阻断新派生，除非有批准的例外。
- **评审**：人工评审快照当时的许可版本，之后许可收窄仍可按当时资料验证（`verify_review`）；记录工程与审美取舍。
- **许可例外**：提交方案的人不能批准自己的例外（职责分离）。
- **仿真回执**：同一会话重传只记录一次；摘要变化把相关候选停入待查，排查后恢复。
- **量产冻结**：候选须评审通过且来源许可当前有效，量产决定后候选冻结。
- **持久化**：每次写操作原子落盘，服务重启后待办（在评审/待查候选、待决例外、临期许可）完整延续。
- **谱系**：`lineage` 沿派生链展示机器建议、人工选择、工程与审美取舍、权属确认如何共同形成当前版本。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
